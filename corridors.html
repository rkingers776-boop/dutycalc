Trade Corridor Directory

The homepage's corridor section shows the fourteen most-trafficked lanes. This page is the full index — every corridor on the site in one place, with the headline duty rate, the destination VAT, and the de minimis threshold that decides whether small parcels clear free. Each row opens the lane's own page, where the rate is unpacked, the compliance points are listed, and a calculator runs the real landed cost.

Rates are MFN base rates unless an FTA is noted; Section 301 and other additional duties are covered on each lane's page. De minimis thresholds are shown for the destination country, with the threshold base (goods value vs. goods-plus-freight) noted where it differs from the US-style goods-value rule — see the de minimis guide for how that changes the math.

Rates shown are the headline MFN / FTA figure for each lane's typical cargo; actual rates vary by HS code, and Section 301, AD/CVD, and other additional duties are detailed on each lane page. The de minimis column shows the destination threshold with its measurement base — "goods value" thresholds are assessed on the value of the merchandise only, "incl. freight" thresholds on the goods-plus-freight consignment value, which is the UK and Japan rule. Every lane page embeds its own calculator using the same landed cost model; the tariff lookup covers codes not listed here.
